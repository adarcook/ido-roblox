# התוכנית המוסכמת — הזיכרון הקבוע של המשחק

עודכן: 30 באוקטובר 2026. המשתמש ביקש לפתח את כל שמונת המפגשים יחד ובמהירות, כדי שעידו יראה עולם שלם, ישחק וייתן פידבק. המפגשים הם תחומי פיתוח, לא שערים שדורשים אישור בנפרד.

1. **Lucky Block והדמות** — לשמר את הבלוק הקיים עם הפנים, הכנפיים המחוברות והנוצתיות ואנימציית הנשיאה. ליטוש לפי פידבק.
2. **טיסה לפני הרחבות לבלוק** — המראה, ירידה, תנועה קדימה ולצדדים ומהירות. קודם שיהיה לעידו כיף לעוף. תמיכה בטאבלט ובמחשב.
3. **אימון תעופה מעץ** — מבנה עץ, גלגל/להבים שמייצרים רוח, ריחוף נגד הרוח וחישוקי עץ באוויר. מדד בסיסי אחד: Flight Power. פיצול ל־Speed / Stamina / Lift הוא אפשרות עתידית.
4. **התקדמות** — אימון משפר מהירות בלבד, תצוגת רמה ושמירת התקדמות. אין מחסום גובה לפי כוח: השחקן יכול לעוף חופשי לגובה שהמפה מאפשרת.
5. **אזור ושומר מעופף** — העולם מחולק למקטעי ביומה תחומים בין קירות. לכל מקטע יש Lucky Blocks צבעוניים ושומר מעופף משלו. הוא לא תוקף לפני הגניבה ולא יוצא מגבולות המקטע שלו.
6. **Steal, Drop & Escape** — גניבת בלוק מעירה את שומר המקטע ומתחילה מרדף באוויר. אפשר לזרוק את הבלוק, להשאיר אותו בעולם ולחזור לקחת אותו. השומר רודף רק בתוך המקטע שלו.
7. **בסיס ואוסף Lucky Blocks** — החזרת בלוק לבסיס צריכה להיות מוחשית וברורה. הבלוקים שהשחקן הביא נשמרים ומוצגים בבסיס; פרסים ומטבעות יכולים להישאר כתוספת, אבל האוסף הפיזי הוא הפידבק המרכזי.
8. **עולם ביומות ושומרים** — רצף מקטעים בצבעים/חומרים שונים (למשל דשא, שלג, אדמה), עם שומרים מעופפים שונים ו-Lucky Blocks בצבעים שונים. ההתקדמות נשענת על מהירות בלבד, ללא חסימת גובה.

## הלולאה

מתאמן בטיסה → מתחזק → עף גבוה ומהר יותר → מחפש Lucky Block → מתגנב למפלצת הישנה → גונב → המפלצת מתעוררת → בורח באוויר → מחזיר לבסיס → מקבל פרס → משתפר.

## החלטות זמניות לגרסת הבדיקה הראשונה

- תפיסה, מוות, יציאה או ביטול נשיאה מחזירים את הבלוק לעץ; אין אובדן התקדמות או מטבעות.
- המפלצת מתעוררת רק בגניבה ורודפת רק אחרי הגנב. אחרי חזרה לבסיס/תפיסה היא חוזרת לישון.
- ארבעה עצים עם דרישות Flight Power של 1, 10, 25 ו־45.
- אימון רוח נותן כוח כל שתי שניות; מעבר בחישוקים נותן בונוס עם המתנה בין שימושים.
- פרס בסיסי כולל מטבעות וכוח טיסה. כל שלוש החזרות משפרות את צבע הכנפיים ואת הטיסה, עד שלוש דרגות.
- פידבק ראשון מעידו: להסיר את מחסום הגובה. השחקן יוכל להגיע לכל גובה שהמפה מאפשרת; האימון ישפר מהירות בלבד.
- הכול ניתן לשינוי לפי הריג'קטים של עידו. זו גרסת alpha למשחק, לא קביעה סופית של איזון ועיצוב.

## מצב

הסבה ל־GitHub, בנייה בענן ופרסום ל־Playtest עובדים ונבדקו בטאבלט. כל שמונת תחומי המשחק מפותחים יחד כעת. אין עדיין אימות אנושי של המערכות החדשות.
